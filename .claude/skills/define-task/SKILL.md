# /define-task

実験タスクの詳細な条件・手順を定義し、`TODO.md` に記録するスキル。

## 手順

### Step 1: ヒアリング

以下の項目をまとめて質問する（分かる範囲で答えてもらえばよい）:

- **タスク名**: 短い識別名
- **目的**: この計算で何を明らかにしたいか
- **系の情報**: 対象分子・タンパク質・系のサイズなど
- **計算手法・ソフトウェア**: GROMACS / AMBER / Gaussian / mdtbx など
- **主なパラメータ**: 温度、圧力、時間スケール、力場など
- **手順**: ステップごとの実行手順
- **期待される結果・評価指標**: 何をもって成功とするか

### Step 2: TODO.md への追記

ヒアリング内容を整理して `TODO.md` に追記する。`TODO.md` が存在しない場合は新規作成する。

フォーマット:

```markdown
## [TASK] タスク名 (YYYY-MM-DD)

**目的**
...

**系の情報**
...

**計算手法・ソフトウェア**
...

**パラメータ**
...

**手順**
- [ ] ステップ1
- [ ] ステップ2
- [ ] ...

**評価指標**
...

**ステータス**: TODO
```

### Step 3: 確認

追記した内容をユーザーに見せて確認を取る。修正が必要なら反映する。
